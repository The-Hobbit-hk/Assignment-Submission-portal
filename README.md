# Joineazy - Assignment & Review Dashboard

This is a Vite + React + Tailwind frontend project for the Joineazy Frontend Intern assignment.

## Features
- Role-based UI (Admin: Professor Rao, Student: Harshvardhan & others)
- Students can submit and confirm their submissions (double-verification)
- Admins can create assignments, attach Drive links per student, and view per-student progress bars
- All data is persisted in localStorage (no backend)
- Student password: "s1" & "s2"
- Admin Password: "profpass"

## Run locally
1. Install dependencies:
```bash
npm install
```
2. Start dev server:
```bash
npm run dev
```

The app is ready for Cursor or any local IDE.
